# DevOps
FastAluno: API de Gerenciamento de Alunos

Este projeto é uma API RESTful criada para realizar as operações de CRUD (Criar, Ler, Atualizar e Deletar) de alunos. Foi desenvolvido em Python, utilizando o framework de alta performance FastAPI.

O principal objetivo é demonstrar um ciclo de desenvolvimento moderno, incluindo:

Desenvolvimento da API: Criação de endpoints robustos e documentados automaticamente.

Testes Automatizados: Implementação de testes de unidade com Pytest para garantir a confiabilidade da aplicação.

Containerização: Uso do Docker para empacotar a aplicação e suas dependências, garantindo um ambiente de execução consistente.

Automação de CI/CD: Configuração de um workflow com GitHub Actions para integrar, testar e empacotar o projeto de forma contínua.
